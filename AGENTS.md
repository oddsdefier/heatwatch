# HeatWatch

Standalone native macOS menu-bar app. Keep Expensh unchanged.
Use system frameworks only. Never request root or change fan settings.
Temperature failures must show unavailable, never zero or guessed values.
Describe process heat sources as likely contributors, never proven causes.
Do not collect command arguments, browser URLs, or credentials.
Validate with swift build -c release, strict compiler checks, and live diagnostics.
Do not commit or push without permission.
